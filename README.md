# Système socio-fiscal

Liens entre les variables du système socio-fiscal dont dépend le revenu disponible dans 
 [OpenFisca-France](https://github.com/openfisca/openfisca-france).

```
pip install -r requirements.txt
python -m ssf                # dernière date 
python -m ssf 2024-01-01     # une autre date : janvier ou juillet, de 2011 à 2026
```
